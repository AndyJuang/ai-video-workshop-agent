# ③ 生成影片

**目標**：每個鏡號都有會動的畫面（S01.mp4…）。三條路，挑一條就好。

| 做法 | 適合誰 | 怎麼做 |
|---|---|---|
| **預設：讓靜態圖動起來** | 所有組別 | 把分鏡圖放進剪輯軟體，加上緩慢的縮放、平移和轉場；搭配旁白就是一支完整短片 |
| 進階 A：AI 圖生影片 | 想讓角色真的動起來 | 把分鏡圖當第一個畫面，用 P4 寫動作與運鏡，生成 3–5 秒片段 |
| 進階 B：HTML／程式做影片 | 想做片頭、字卡、數據動畫 | 請會寫程式的 AI 助理寫網頁動畫程式，再算圖輸出成 MP4 |
| 進階 C：NotebookLM 影片摘要 | 說明型、簡報式影片（例如政策法規、課程模式） | 上傳自己的腳本、分鏡、資料，用 P4-2 產生有旁白的說明影片 |

## 預設：縮放平移

在剪輯軟體（Clipchamp、iMovie、手機剪輯 App）放進分鏡圖，加緩慢的縮放、平移和轉場。這一步也可以留到第五階段一起做。

## 進階 A：AI 圖生影片（提示詞：[P4](../prompts/P4-image-to-video.md)）

| 工具 | 可以做什麼 |
|---|---|
| Google Flow（Veo 模型） | 上傳起始畫面（也可以加結束畫面），描述中間的動作，生成短片段 |
| Google Gemini app（Gemini Omni） | 用文字或照片生成短片，再用對話修改 |
| Kling（可靈 AI） | 圖生影片，可設定首、尾畫面 |
| Runway | 上傳的圖就是第一個畫面，提示詞只要寫動作、運鏡和節奏 |

- 網路上很多舊教學用的 OpenAI Sora，已於 2026 年停止服務，不要照舊教學操作。
- 每個工具能用的功能依帳號而不同；用不了就走預設做法。

**四步驟**：① 選一張分鏡圖 → ② 用 P4 寫「一個動作＋一種運鏡」→ ③ 生成 3–5 秒，失敗就換 P4 的保守版 → ④ 依鏡號存檔（S03.mp4）。

**運鏡小抄**：鏡頭固定／緩慢推近／緩慢拉遠／由左往右平移／由下往上搖。一個片段只用一種。

## 進階 B：HTML／程式做影片（需要能執行指令的程式助理）

| 工具 | 是什麼 | 需要什麼 |
|---|---|---|
| HyperFrames | 開源框架（Apache-2.0）：用 HTML、CSS 寫畫面，算圖成 MP4；官方另有免費的 Studio 桌面 App | 命令列版需要 Node.js 22 以上與 FFmpeg |
| Remotion | 用 React 程式做影片；個人可以免費使用（公司另有授權規定），原始碼公開但不是開源授權 | Node.js |
| Motion Canvas | 開源（MIT）的 TypeScript 動畫函式庫，附即時預覽編輯器 | Node.js |

進階參考（只在學生主動問、環境也支援時才提）：MotionSites（動態設計提示詞參考庫，只學寫法）、huashu-motion（開源 skill，MIT）、cinematic-skill（開源 skill，MIT，畫面由程式逐格畫出，不是生成式影片，專案很新）、OpenFilm（開源，MIT，仍是 0.x 版）、Prompt Motion（動態影片提示詞庫；提示詞屬於原分享者，只當結構參考、改寫成自己的內容，展出時註明參考來源）、Pixel Path（開源 skill，MIT；輸出是 HTML 網頁，不是影片檔）。這些都要搭配能執行指令的程式助理；**Claude Code 需付費方案**。

## 進階 C：NotebookLM 影片摘要（提示詞：[P4-2](../prompts/P4-2-notebooklm-video-overview.md)）

NotebookLM 已改名為 **Gemini Notebook**（同一個產品）。它的「影片摘要」（Video Overview）會把你上傳的來源做成有旁白的說明影片。

1. **建筆記本、上傳來源**：只放自己組的總腳本、分鏡表、整理好的資料。
2. **開啟影片摘要**：在右側 Studio 面板選 **Video Overview**，進入自訂。
3. **選設定**：格式選 **Explainer** 或 **Short**（Cinematic 只支援英文，不適合）；語言選 **Chinese (Traditional)**；視覺風格（Explainer 才有，限 18 歲以上使用者）建議和第二階段的風格一致。
4. **貼上 P4-2、產生**：可以打開 **Review producer notes** 先看製作筆記。完成後在 Studio 播放或下載。

影片和旁白都是 AI 生成，Google 提醒可能有錯誤或聲音瑕疵，一定要看完查核。用 Gmail 帳號即可免費註冊；多數學校帳號也可使用。

## 產出檔案

- `video/S01.mp4`、`video/S02.mp4`…（依鏡號；縮放平移在剪輯階段做的話可以省略）
- 每個片段用過的提示詞與工具記進 `project-log.md`

## 關卡檢查表

- □ 每個鏡號都有畫面（片段或要做縮放平移的靜態圖）
- □ 每個片段只有一個動作、一種運鏡，3–5 秒
- □ 角色外觀沒有改變、沒有多出人物、畫面沒有文字
- □ 用 NotebookLM 的話：內容都來自自己上傳的來源，旁白是繁體中文，已看完查核

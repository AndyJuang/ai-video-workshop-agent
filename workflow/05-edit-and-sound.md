# ⑤ AI 影片剪輯／音效

**目標**：把片段、旁白、字幕、音樂音效接成 1–3 分鐘的短片，片尾有 AI 生成標示與資料來源。**工具負責剪輯，品味由你決定。**

## 兩條路

- **預設**：用剪輯軟體照總腳本第 ⑨ 部分的剪輯清單拖拉剪接。
- **進階**：把素材交給「能讀寫你電腦資料夾的 AI 助理」，照下面五步讓 AI 初剪，你負責審核和修改。

## 預設路線：新手剪輯軟體

| 工具 | 適合做什麼 |
|---|---|
| Clipchamp（Windows／網頁） | 拖拉剪輯；有自動字幕，可以下載 SRT 字幕檔 |
| iMovie（Mac／iPhone／iPad） | 拖拉剪輯；沒有自動字幕，字幕要手動加文字 |
| 手機剪輯 App | 隨手剪；依剪輯清單排好即可 |

**剪輯順序**：依剪輯清單排片段 → 放旁白並對齊 → 上字幕 → 加音樂音效（音量比旁白小）→ 片尾：AI 生成標示、資料來源、組員 → 輸出 MP4。

## 進階：AI 剪輯五步

| 步驟 | 做什麼 | 提示詞 |
|---|---|---|
| 01 找 AI 助理 | 用能讀寫本機資料夾的 AI 助理（不是網頁聊天視窗） | — |
| 02 建資料夾 | 見下方「資料夾對照」 | [P6-1](../prompts/P6-1-setup.md) |
| 03 裝工具 | 檢查、安裝 FFmpeg、Whisper、HyperFrames 等工具；**先問再裝**，不刪原始檔 | [P6-1](../prompts/P6-1-setup.md) |
| 04 給品味 | 給 3–5 支風格參考，研究節奏、字幕、顏色和動態。**參考就好，不要照抄；保留我的臉、我的聲音、我的風格** | [P6-2](../prompts/P6-2-style-reference.md) |
| 05 初剪再改 | AI 初剪（剪空白、上字幕、配樂、排版），先給剪輯計畫，同意後才剪；再用大白話修改 | [P6-3](../prompts/P6-3-edit.md) |

**能讀寫本機資料夾的 AI 助理**（2026/11/17 依官方說明查核；能不能用依帳號而定，用不了就走預設路線）

**AI 會幫你裝的工具**

| 工具 | 用途 | 備註 |

| FFmpeg | 剪接、配音、上字幕、改尺寸、輸出 | 免費開源 |
| Whisper | 在自己電腦把旁白轉成字幕（SRT） | OpenAI 開源（MIT），本機執行；專有名詞要人工校對 |

### 資料夾對照（P6 提示詞用的是講義的資料夾名稱）

P6-1、P6-3 會提到「原始素材／參考影片／匯出成品」。在這個 repo 的專案結構裡，對照如下；AI 助理照這張表找檔案，**不要複製或搬動前四階段的檔案**：

| P6 提示詞裡的名稱 | 本專案的位置 |
|---|---|
| 原始素材／分鏡圖 | `images/` |
| 原始素材／影片片段 | `video/` |
| 原始素材／旁白 | `audio/`（narration.mp3） |
| 原始素材／字幕 | `edit/subs.srt` |
| 參考影片 | `edit/參考影片/`（只放自己拍或有授權的影片） |
| 匯出成品 | `edit/匯出成品/`（每一版另存，例如 初剪_v1_16x9.mp4） |
| 風格說明.md | `edit/風格說明.md` |

如果學生想完全照講義的資料夾結構做，也可以；先問學生要哪一種。

**給 AI 回饋的小技巧**：用大白話、一次講一件事，例如「Hook 標題再大一點」「第 3 鏡多停 1 秒」「音樂小聲一點，旁白要聽得清楚」；改完看一次再講下一件，每改一次另存一版。

## 特效：一支影片 1–3 個就好

易：動態大標、人物推進、對話氣泡、圓環進度、前後滑桿、數據增長（數字一定附來源）。中：卡片環繞、穿越轉場。難（★ 需要把人物去背）：背後大字、霓虹描邊、動作殘影、分身同框、定格介紹。第一次做建議先選「易」的。寫法範例見 [特效需求範例](../prompts/FX-effect-request-example.md)。

## 音效與背景音樂：找、對、做

**找（預設，免費）**

| 來源 | 授權重點 |
|---|---|
| Casper 免費音效（https://www.casper.tw/sound-effects/zh-tw/），繁體中文介面、不用註冊 | 網站自己的授權頁：課堂、展出、放上網路都可免費用；標示出處不強制但建議寫 |
| Pixabay 音效庫（https://pixabay.com/sound-effects/） | 可免費使用、不必標示作者（標了更好）；不可把原檔單獨再分發或販售 |
| Freesound（https://freesound.org/） | 每個音效授權不同，先篩 **CC0**；用到 CC BY 要標示作者，CC BY-NC 不能用在營利用途；下載原檔要先註冊免費帳號 |
| Openverse（https://openverse.org/） | 只是搜尋目錄，篩 **CC0**，跟著每一筆的授權標示來用 |
| **背景音樂**：Casper 免費背景音樂（https://www.casper.tw/free-music/zh-tw/） | 同一個網站的配樂庫，不用註冊；每首曲子都有曲目編號 |

**Casper 音效與背景音樂的使用規則**（依官方授權頁整理）

- 兩邊的檔案都是網站自己用 AI 生成、自己放上網的，不是轉載別的音效庫或音樂庫。
- 可以免費用在課堂作業、成果展、放上網路的影片。
- 標示出處不強制，但建議寫：「音效：www.casper.tw/sound-effects」「音樂：曲名（曲目編號），來自 casper.tw/free-music/」。
- 不要：把檔案登記到 Content ID 或類似的版權比對系統；重新打包成自己的音效包或音樂庫轉發；拿去訓練 AI；把音樂說成真人作曲或真人演奏。
- 寫進音效清單：音效或曲目編號、頁面網址、下載日期。

另一個來源（進階）：OpenFilm 內建素材庫（官方標示 CC0），用了仍要記下來源。

**對（進階）：Real SFX**：給 Claude Code 用的免費技能，從**自己有權使用的音效資料夾**挑真實錄音，放到畫面對應的那一格；它不會生成聲音，而且 AI 聽不到聲音，放完要自己聽。

**做（進階）**

- earshot：免費開源（MIT）指令列工具，用程式合成音效，也能回聽成品，標出慢半拍或太大聲的地方。需要 Python 3.10 以上、uv 與 FFmpeg。講義中的指令依官方文件整理，未在課堂電腦實際執行。
- MMAudio：依影片或文字生成對得上畫面的聲音，官方有免費網頁試用。程式碼是 MIT，但**官方模型權重是 CC-BY-NC 4.0，只能非商業使用**；生成結果要自己聽過。

**三個技巧**：音效放在獨立的一軌（在旁白和音樂下面）；對準畫面跳出、文字出現的那一格；音量比人聲小。

**音效四大坑（匯出前逐項打勾）**：① 慢半拍 ② 蓋過人聲 ③ 授權不明（不確定就不用）④ 配音自己錄到崩潰（改用第四階段的 AI 語音並標示）。AI 聽不到聲音，最後一關一定是你的耳朵：耳機、喇叭各聽一次。

## AI 底下在跑的指令：FFmpeg

四個指令（統一尺寸、依序接起來、配上旁白、燒上字幕）在 [FFmpeg-commands.md](../prompts/FFmpeg-commands.md)；2026/11/17 在 FFmpeg 7.1 實測。補充：

- 先在終端機輸入 `ffmpeg -version` 確認已安裝。
- 直式 9:16：把第 ① 個指令中兩處 `1920:1080` 改成 `1080:1920`。
- 第 ② 個指令要先建立 list.txt，一行寫一段：`file 'S01.mp4'`。
- 第 ③ 個指令的 `-shortest` 會讓輸出長度等於影片和旁白中較短的那一個。
- 第 ④ 個指令：Mac 把 `Microsoft JhengHei` 改成 `PingFang TC`；字幕檔存成 UTF-8。
- 出現錯誤訊息時，把訊息整段貼回給 AI，請它說明原因並修改指令。

**DaVinci Resolve＋MCP（實驗、選修）**：外部腳本只在 Resolve Studio 版提供，免費版不支援；先用預設工具或 AI 剪輯五步完成作品。

## 關卡檢查表（交件前）

- □ 影片長度符合要求；需要的比例都有輸出
- □ 字幕和旁白對齊，每行 16 字以內，錯字已校對
- □ 特效不超過 3 個，每個都說得出它幫故事說清楚了什麼
- □ 音效比旁白小，對準畫面；耳機、喇叭都聽過
- □ 每個音效、音樂都在音效清單裡，有來源與授權
- □ 片尾有：「本作品部分畫面／文字／語音由 AI 協助生成，內容經小組查核與修改。」、資料來源（含音效來源）、組員名單
- □ 原始素材沒有被刪除、覆蓋或移動

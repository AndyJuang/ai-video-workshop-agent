# ④ AI 配音

**目標**：一段時間剛好、好聽清楚的旁白（narration.mp3）。

**用的提示詞**：[P5 配音稿與 AI 語音指示](../prompts/P5-voiceover.md)，輸入總腳本第 ⑧ 部分。

## 預設：自己錄（照配音稿唸）

1. 用 P5 把旁白整理成配音稿：標好停頓（／）、加重的詞（【】）和語氣。
2. 找安靜、有布料（窗簾、衣櫃）的小房間；手機距離嘴巴約一個拳頭到一個手掌寬，略偏一側，避免噴麥。
3. 開頭先空 2 秒安靜；一句一句錄，唸錯就停一拍，從那一句重唸。
4. 以每秒約 3 字為準，比平常說話慢一點；錄完全組一起聽一次再定稿。
5. 檔名：narration.mp3（或依鏡號分段：N01.m4a、N02.m4a…）。

## 進階：AI 語音（API，通常需要開發者帳號與金鑰）

| 服務 | 可以做什麼 | 要注意 |
|---|---|---|
| OpenAI Audio API（Text to speech） | 文字轉語音，可以用文字指示語氣 | 官方要求清楚告知聽眾這是 AI 語音；內建聲音以英文最佳化，中文先試聽 |
| Google Gemini API 語音生成／Google Cloud Text-to-Speech | 文字轉語音，可用風格指示控制語氣，支援兩位說話者 | 中文先試聽 |
| ElevenLabs | 文字轉語音、聲音複製，支援中文 | 複製聲音時必須聲明已取得聲音本人同意 |

## 進階：開源套件（只複製**你自己**的聲音）

| 套件 | 授權 |
|---|---|
| GPT-SoVITS | 程式與官方模型：MIT |
| F5-TTS | 程式：MIT；官方預訓練模型：**CC-BY-NC 4.0（僅限非商業）** |
| CosyVoice | Apache-2.0 |
| VoiceStudio（進階參考，在自己電腦執行的配音軟體） | 程式碼 AGPL-3.0；**預設模型權重是非商業授權（CC-BY-NC）**：課堂與展覽可以用，商業用途不行。只從官方 GitHub 的 Releases 頁面下載安裝檔 |

- 這些套件要在自己電腦安裝 Python 環境（VoiceStudio 有桌面安裝檔），只從官方 GitHub 下載。
- 開源授權只管「程式能不能用」，**不代表你有權使用別人的聲音**。

## 聲音安全規則（一定要遵守）

- **只複製你自己的聲音**，而且是你自己同意的。
- 不複製同學、老師、家人、名人的聲音；確有需要，必須先取得對方**書面同意**。
- **不使用任何幼兒的聲音或臉**。
- 不模仿真實人物或卡通角色的聲音。
- 使用 AI 語音時，片尾標示：「本片旁白使用 AI 語音生成」。

## 產出檔案

- `script/配音稿.md`（P5 的輸出）
- `audio/narration.mp3`（或 `audio/N01.m4a`…）

## 關卡檢查表

- □ 每句估計秒數都不超過該鏡秒數，總長符合片長
- □ 全組聽過一次，咬字清楚、沒有雜音
- □ 用了 AI 語音或聲音複製：只用自己的聲音（或有書面同意），已記下要在片尾標示

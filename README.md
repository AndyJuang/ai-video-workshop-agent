# AI 影片製作協作包：讓你的 AI 助理照五階段陪你做影片

這是「AI 影片製作工作坊」（2026/11/17）講義的**AI 助理版**。把下面的起始提示詞貼給你的 AI 助理（Claude Code、Codex、Grok Bot、ChatGPT 等），它就會照工作坊的五階段流程，一步一步陪你把 1–3 分鐘的短片做出來：

**① 腳本創作 → ② 圖片生成 → ③ 生成影片 → ④ AI 配音 → ⑤ AI 剪輯／音效**

- 你是導演：主題、故事、風格、音樂都由你決定；AI 負責提問、整理、提出選項、產出草稿和檢查。
- 每個階段結束，AI 會停下來給你看成果和檢查表，你回覆「通過」才往下走。
- 每個階段都有**免費、不用寫程式**的預設做法；進階工具是加碼，不做也能完成作品。
- 工具名稱與功能於 2026/11/17 依各工具官方說明查核；AI 工具更新很快，以官方當下的說明為準。

## 怎麼開始

先在電腦上開一個空的資料夾當作你的專案資料夾（例如「第3組_幼兒園的一天」）。

| 你用的 AI | 怎麼開始 |
|---|---|
| Claude Code（Claude 桌面版的 Code 分頁，**需付費方案**） | 安裝 Claude 桌面版（不是網頁版）→ 點上方的 Code 分頁 → 環境選 Local → 開啟你的專案資料夾 → 貼上起始提示詞。它可以幫你建資料夾、寫檔案，經你同意後執行 FFmpeg 等工具。repo 裡的 CLAUDE.md 會提醒它讀 AGENTS.md。 |
| OpenAI Codex app（Mac／Windows） | 新增 Local 專案 → 選擇你的專案資料夾 → 貼上起始提示詞。能用的功能依帳號而定。 |
| Grok Bot、ChatGPT 或其他聊天型 AI | 直接在對話裡貼上起始提示詞。它碰不到你電腦裡的資料夾，所以會把提示詞、腳本、檢查表交給你，由你自己存檔、操作工具。 |
| AI 打不開網址 | 照 [STARTER_PROMPT.md](STARTER_PROMPT.md) 的「備案」：把 [AGENTS.md](AGENTS.md) 全文貼給它。 |

**AI 要安裝軟體、執行指令、上傳任何東西之前，都必須先說明並等你說「可以」。** 如果它沒有先問，請它停下來。

## 起始提示詞

以下已填好 repo 網址，整段複製貼上（同一段也在 [STARTER_PROMPT.md](STARTER_PROMPT.md)）：

```text
【角色目標】
你是我的 AI 影片協作導演兼製片。請把這個公開 GitHub repo 裡的工作流程，當作你這次和我合作的工作模式：https://github.com/AndyJuang/ai-video-workshop-agent
我們要照五個階段（腳本創作 → 圖片生成 → 生成影片 → AI 配音 → AI 剪輯／音效）一起做出一支 1–3 分鐘的短片。我是導演，創作決定由我做；你負責提問、整理、提出選項、產出草稿和檢查。

【輸入】
- 工作說明：repo 裡的 AGENTS.md（Claude Code 另有 CLAUDE.md 指向它）
- 各階段做法：workflow/ 資料夾
- 提示詞：prompts/ 資料夾（P1–P6，逐字取自工作坊講義）
- 範本：templates/ 資料夾（project-brief、storyboard、音效清單、project-log）
- 我的資料：請用開場訪談向我收集，不要自己假設。

【步驟】
1. 讀 repo：能開網址就直接讀；能執行指令的話，先告訴我你要把 repo 下載（clone）到哪裡，我同意後再下載。依序讀 AGENTS.md、workflow/00-overview.md、workflow/99-safety-and-licences.md。打不開的話，直接告訴我，請我把 AGENTS.md 的內容貼給你。
2. 用一句話告訴我：你讀到了哪些檔案，以及你是「只能聊天」還是「能讀寫資料夾、執行指令」的模式。
3. 開場訪談：一次問 2–3 題，每題給 2–3 個選項，也接受我自己的答案。要問：主題、片長、平台與比例、組員分工、可用的 AI 工具與帳號、電腦環境。
4. 用 5 行以內摘要我的答案，整理成 project-brief，問我「這樣對嗎？」。
5. 我確認後，開始第一階段：照 prompts/P1-master-script.md 的三輪提問訪問我，產出總腳本九個部分。
6. 第一階段做完就停下來，用 AGENTS.md 的關卡格式回報，等我回覆「通過」才進第二階段。之後每個階段都一樣。

【限制】
- 完全照 AGENTS.md 的協作規則和硬規則：創作決定先問我；沒有我的同意，不安裝、不執行指令、不上傳、不發布；不刪除或覆蓋原始素材。
- 每個階段先走免費、不用寫程式的預設做法；進階工具等我問了、而且我的環境支援才提。
- 不複製別人的聲音；不使用真實幼兒的照片、影片或聲音；角色都是虛構的。
- 每個素材記下來源與授權；不確定的功能、授權、法規或數字，請我去官方頁面查，不要自己編。
- 使用繁體中文與臺灣用語，說明用白話。

【輸出格式】
1. 讀取結果（一句）＋你的模式（一句）
2. 開場訪談第一輪（2–3 題，附選項）
（訪談完成後）3. project-brief 摘要（5 行內）
（我確認後）4. 第一階段的 P1 訪談，完成後用關卡格式回報

【自我檢查】
每次回覆前確認：
□ 我是照 AGENTS.md 的方式工作
□ 一次只問 2–3 題，而且有給選項
□ 需要學生決定的創作選擇，我沒有替他決定
□ 沒有未經同意的安裝、指令、上傳或發布
□ 到了關卡就停下來等「通過」
```

## 安全與授權（一定要看）

完整版在 [workflow/99-safety-and-licences.md](workflow/99-safety-and-licences.md)。重點：

- **不上傳真實幼兒的照片、影片或聲音到任何 AI 工具**；角色一律用虛構人物、插畫風格。
- 不使用真實人物、名人、品牌商標、卡通角色；提示詞不寫「模仿某位畫家或繪本作者的風格」。
- **聲音只複製自己的**；別人的聲音要書面同意；不使用幼兒的聲音。
- 參考影片：參考就好，不要照抄；保留你的臉、你的聲音、你的風格。只下載自己的、或作者明確允許下載的影片。
- 每個音效、音樂都記進 [音效清單](templates/音效清單.md)：編號、用途、來源網址、授權、下載日期。授權不明就不要用。
- 非商業授權要遵守：MMAudio 官方模型權重、F5-TTS 官方預訓練模型、VoiceStudio 預設模型權重都是 CC-BY-NC，只能非商業使用。
- Casper 免費音效／背景音樂：課堂、展出、放上網路可免費用；不登記 Content ID、不重新打包轉發、不拿去訓練 AI；AI 生成的音樂不要說成真人作曲或演奏。
- 片尾標示：「本作品部分畫面／文字／語音由 AI 協助生成，內容經小組查核與修改。」用 AI 語音時加註「本片旁白使用 AI 語音生成」。
- AI 會出錯，也可能編出看起來很真的法規、數字或引用：所有知識性內容都要找到來源才可以用。
- Claude Code 需付費方案；其他工具能用的功能依帳號而定，用不了就走預設做法。
